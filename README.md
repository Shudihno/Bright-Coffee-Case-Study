## 📌 Project Overview

**Bright Coffee** is an end-to-end data analytics project analysing coffee shop sales transactions to understand **revenue performance, product performance, customer purchasing patterns, store performance and sales trends**.

The project follows a complete analytics workflow:

> **Planning → Data Cleaning → SQL Analysis → Dashboard Design → Dashboard Development → Business Insights → Recommendations**

The goal was not only to analyse the data, but to transform the analysis into an **executive-friendly decision-support dashboard**.

The project includes:

* 🗺️ Project planning using **Miro**
* 🎨 Dashboard and presentation design using **Canva**
* 🧹 Data cleaning and preparation
* 🗄️ SQL-based data analysis
* 📊 Interactive dashboard development
* 🌐 A live web-based executive dashboard
* 💡 Automated business insights and recommendations
* 📁 GitHub documentation and version control

# 🎯 Business Recommendations

Based on the analysis, several actions can be considered:

### 1. 📦 Optimise Inventory

Increase inventory coverage for high-performing products to reduce the risk of stockouts during peak periods.

### 2. 📣 Promote Underperforming Products

Use bundles, counter placement or promotions to increase demand for weaker-performing products.

### 3. 🕐 Target Slow Trading Periods

Introduce time-based promotions during low-revenue periods to improve utilisation of quieter hours.

### 4. 👥 Optimise Staffing

Increase staffing coverage during peak trading periods to maintain service levels and reduce customer waiting times.

### 5. ☕ Focus Marketing on High-Value Categories

Coffee remains a significant contributor to revenue, making it an important category for targeted campaigns.

### 6. 🎁 Use Loyalty Promotions

Offer targeted loyalty incentives during quieter periods to encourage customers to shift some demand away from peak hours.
