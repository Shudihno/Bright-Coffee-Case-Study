# ☕ Bright Coffee — Sales Analytics Project

> **An end-to-end data analytics project transforming coffee shop sales data into actionable business insights and executive dashboards.**

## 🚀 Live Dashboard

### [☕ View the Bright Coffee Executive Dashboard →](https://coffee-ceo-view.lovable.app)

An interactive web-based dashboard providing an executive view of **revenue, sales, products, stores, trends, peak periods, insights and recommendations**.

---

## 📌 Project Overview

Bright Coffee analyses coffee shop transaction data to understand:

* 💰 Revenue and sales performance
* ☕ Product & category performance
* 🏪 Store performance
* 📅 Monthly and daily trends
* ⏰ Peak trading periods
* 🧾 Orders and quantity sold
* 💡 Business insights and recommendations

The project follows the complete analytics lifecycle:

**Planning → Data Preparation → SQL Analysis → Dashboard Development → Data Storytelling → Recommendations**

---

## 🧭 Planning & Design

### 🗺️ Miro

Used to plan the project, define business questions, identify KPIs and structure the analytical workflow.

### 🎨 Canva

Used for visual planning, presentation design and communicating analytical findings.

### 📊 PowerPoint

Used to create the final business presentation and communicate key insights and recommendations to stakeholders.

---

## 🗄️ Data Analysis

### Databricks SQL

Used for data preparation, transformation and analysis, including:

* Revenue analysis
* Product performance
* Category analysis
* Store performance
* Time-based analysis
* KPI calculations
* Sales trends

### Excel

Used for data inspection, preparation, validation and supporting analysis.

---

## 📊 Business Intelligence & Visualisation

### Power BI + DAX

Used to build analytical dashboards, create calculated measures and deliver interactive business intelligence.

### Google Data Studio

Used to create additional data visualisations and explore different approaches to presenting the analysis.
